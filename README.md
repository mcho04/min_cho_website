# Min Cho Website

A simple static personal website.

## Files

- `index.html` - edit your name, experience, education, projects, links, and email here.
- `project-1.html`, `project-2.html`, `project-3.html` - edit each project detail page here.
- `styles.css` - edit colors, spacing, and layout here.
- `profile.jpg` - add this file to show your picture.
- `project-1.jpg`, `project-2.jpg`, `project-3.jpg` - add these files to show project pictures.
- `resume.pdf` - add this file so the Resume link downloads your resume.

## View The Site

Open `index.html` in your browser, or run:

```bash
open index.html
```

No Node, build step, or localhost server is required.
